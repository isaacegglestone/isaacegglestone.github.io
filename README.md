# isaacegglestone.github.io

Personal portfolio site, built with [Astro](https://astro.build) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

It also hosts the home page (`/assistant/`) and privacy policy (`/privacy/`) for **Isaac Assistant**, a private OAuth app used to manage my own Gmail and Google Calendar.

## Local development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to ./dist
```
