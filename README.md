# isaacegglestone.github.io

Personal portfolio site, built with [Astro](https://astro.build) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

It also hosts the home page (`/assistant/`) and privacy policy (`/privacy/`) for **Isaac Assistant**, a private personal application.

## Local development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to ./dist
```

## Diagrams

The SVG diagrams in `public/images/` are generated by `python3 scripts/gen_diagrams.py`. Edit the script, not the SVGs.
